# Phase 0 — Truth Pack

**Project:** The Bakery Sketchbook (internal working name, not a public tagline)
**Subject:** BB's Bakery, Los Angeles
**Status:** Unofficial private sales mockup. BB's Bakery has not commissioned, reviewed, or approved this work. There is no relationship with the business. Do not publish, index, or present as official.
**Compiled:** 2026-09-27

This file is the single reference for what the concept may say. Every line of site copy must trace back to a row in Tier A, or be visibly marked provisional (Tier B) or held for owner confirmation (Tier C).

---

## How to read the tiers

| Tier | Source | May appear on the concept site? |
| --- | --- | --- |
| **A — Verified listing** | The Yelp business listing, as supplied by the project owner in the Phase 0 brief | Yes, as plain fact |
| **B — Customer-reported** | Statements that appear only inside Yelp customer reviews (supplied in the brief) | Only as a clearly labeled *sample / provisional* selection, never as an official promise |
| **C — Found elsewhere, unconfirmed** | Public web sources found during research that are *not* in the Yelp export | No. Held for owner confirmation. Listed here so nobody re-discovers and accidentally ships them |

> The Yelp export file itself was not attached to this session. The brief's "Verified information" block is treated as the export's content. The live Yelp page returned a device-verification wall in the research browser and was not bypassed.
